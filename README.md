# StudyDeadline — Telegram-бот дедлайнов

## Возможности
- `/start` открывает главную страницу.
- Добавление задания: название + дата сдачи.
- Список активных дедлайнов и список выполненных.
- Кнопка «Выполнено» закрывает задачу и прекращает напоминания.
- Напоминания ежедневно в 09:00 по часовому поясу `TIMEZONE`.
- Для срока от 14 дней: за 14, 7 и 1 день.
- Для срока от 1 до 13 дней: за 3 и 1 день (напоминание за 3 дня отправляется, только если до срока действительно осталось 3 дня).
- SQLite хранит задания и отметки уже отправленных напоминаний.

## 1. Создай Telegram-бота
1. Открой https://t.me/BotFather
2. Отправь `/newbot`.
3. Укажи имя `StudyDeadline` и username, который заканчивается на `bot` (например, `StudyDeadlineHelperBot`, если свободен).
4. Скопируй токен. Не публикуй его и не отправляй в открытые чаты.

## 2. Локальный запуск
Нужен Python 3.11 или новее.

```bash
python -m venv .venv
# macOS/Linux:
source .venv/bin/activate
# Windows PowerShell:
# .venv\\Scripts\\Activate.ps1

pip install -r requirements.txt
```

Создай `.env` (или задай переменные окружения вручную):
- `BOT_TOKEN` — токен от BotFather
- `TIMEZONE=Europe/Berlin`
- `DB_PATH=studydeadline.sqlite3`

Запуск:
```bash
python main.py
```

## 3. Размещение на Render
1. Создай приватный GitHub-репозиторий и загрузи в него файлы проекта.
2. На Render выбери **New → Blueprint**, подключи репозиторий и подтверди `render.yaml`.
3. В настройках сервиса добавь секретную переменную `BOT_TOKEN`.
4. Убедись, что диск смонтирован в `/var/data`.
5. Запусти Worker и открой Telegram-бота → `/start`.

Для постоянной работы используй постоянно работающий Worker и постоянный диск. Бесплатные тарифы с засыпанием/ограничениями фоновых процессов не подходят для надёжной доставки напоминаний.

## Важно
- Время напоминаний сейчас задано на 09:00 по `Europe/Berlin`. Для другого региона измени `TIMEZONE` на IANA timezone, например `Europe/Moscow`.
- Если бот был выключен ровно в день напоминания, пропущенное уведомление автоматически не догоняется.
- Дедлайны привязаны к Telegram user ID и видны только тому пользователю, который их создал.
